# 京东云雅典娜 AX6600（RE-CS-02）刷机教程

> ⚠️ **刷机有变砖风险。请严格按步骤操作，先备份再动手。** 变砖可用高通 9008（EDL）模式救回。

## 0. 准备工作

| 项目 | 说明 |
|------|------|
| 电脑 | Windows，需有线网卡 |
| 网线 | 直连路由器 LAN 口（刷机期间**禁用无线**） |
| 终端 | PuTTY（telnet）或 Xshell |
| 文件服务器 | hfs.exe，或用 U 盘替代 |
| 刷机文件 | 不死 U-Boot、GPT 大分区表、本固件 factory.bin |
| 救砖工具 | 高通 9008 驱动 + QFIL（备不时之需） |

## 1. 利用漏洞开启 telnet

1. 网线连路由器 LAN 口，浏览器打开 `192.168.68.1`（或 `jdcloudwifi.com`），用管理密码登录。
2. 按 `F12` 打开开发者工具 → Console 标签，输入 `allow pasting` 回车。
3. 粘贴运行（把 `<cmd>` 部分按需替换）：

```js
(async () => {
  const session = document.cookie.split('; ').find(r => r.startsWith('sessionid='))?.split('=');
  if (!session) { console.error('未登录'); return; }
  const exec = async (cmd) => {
    await fetch('/jdcapi', { method: 'POST', body: JSON.stringify({
      jsonrpc: '2.0', id: 1, method: 'call',
      params: [session, 'jdcapi.static', 'set_port_forward', {
        'on-off': 1, name: 't1', proto: 'TCP',
        'src-dport': `1234;\`${cmd}\``, ipaddr: '192.168.1.100',
        'dest-port': '80', edit: 1 }]
    })});
  };
  try {
    await exec('factory_hm info telnet 1');
    await exec('telnetd');
    console.log('Telnet 已开启: 路由IP:23, 账号 root, 密码=后台管理密码');
  } catch (e) { console.error('开启失败', e); }
})();
```

4. telnet 登录：IP `192.168.68.1`，端口 `23`，账号 `root`，密码 = 后台管理密码。

## 2. 备份原厂数据（强烈建议）

```sh
mkdir -p /mnt/mmcblk0p27/original_backup
# 整盘前 1100M 备份（覆盖 GPT + 系统分区）
dd if=/dev/mmcblk0 bs=1M count=1100 of=/mnt/mmcblk0p27/original_backup/all_backup.img conv=fsync
sync
```

> 建议分区分开备份（GPT、p1~p26），便于单独还原。备份完成后通过 Samba（京东云 App 打开 Samba，访问 `\\192.168.68.1`）把文件拷到电脑。**刷 GPT 之前务必确认备份已拷出。**

## 3. 刷不死 U-Boot

1. 准备 U-Boot 文件（亚瑟/雅典娜通刷，如 `uboot-JDC_AX1800_Pro-AX6600_Athena-*.bin`）。
2. 传文件到路由器（U 盘或 hfs）：
   ```sh
   mkdir -p /mnt/sda1 && mount /dev/sda1 /mnt/sda1
   cp /mnt/sda1/uboot-*.bin /tmp/
   ```
3. 核对 md5 后双分区写入（p13 主 + p14 备份）：
   ```sh
   md5sum /tmp/uboot-*.bin   # 必须与发布值一致
   dd if=/dev/zero of=/dev/mmcblk0p2
   dd if=/dev/zero of=/dev/mmcblk0p3
   dd if=/tmp/uboot-*.bin of=/dev/mmcblk0p13 conv=fsync
   dd if=/tmp/uboot-*.bin of=/dev/mmcblk0p14 conv=fsync
   sync && reboot
   ```

## 4. 进 U-Boot Web 后台

1. 断电，**按住 reset 不放**再上电，LED 红灯闪 5 次变蓝灯后松手。
2. 电脑网卡设静态 IP：`192.168.1.11` / 掩码 `255.255.255.0`（**不是自动获取**）。
3. 浏览器（Chrome/Edge）打开 `192.168.1.1`，进入蓝色 U-Boot 页面。

## 5. 刷 GPT 大分区表（扩容 rootfs）

原厂 rootfs 仅 60M，装不下定制固件，须先刷扩容 GPT。

1. 在 U-Boot 页面 `img.html` 上传 **雅典娜专用 GPT**（如 `gpt-AX6600-rootfs2048M.bin`，注意亚瑟/雅典娜 GPT 文件**不通用**）。
2. 写入 GPT。

## 6. 刷入 AthenaWrt 固件

1. 在 U-Boot 首页 `192.168.1.1` 上传本固件 **`*-factory.bin`** 刷写。
2. 等待写入完成，重启。
3. 刷完把电脑 IP 改回自动获取。

## 7. 首次登录

| 项目 | 值 |
|------|----|
| 地址 | `192.168.1.1` |
| 用户 | `root` |
| 密码 | `password` |

登录后**立即修改 root 密码与 Wi-Fi 密码**。

## 8. 变砖救回（9008 / EDL）

- 短接 `R656 + GND` 后上电，设备管理器出现 `Qualcomm HS-USB QDLoader 9008`。
- 用 QFIL / EDL 工具刷入临时 U-Boot，再按 U-Boot → GPT → 固件 顺序重建。
