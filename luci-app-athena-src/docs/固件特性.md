# 固件特性与插件清单

本固件基于 ImmortalWrt（master / snapshot），目标 `qualcommax/ipq60xx`，设备 `jdcloud_re-cs-02`（IPQ6010）。

## 完整插件清单

### 界面与主题
- LuCI（HTTPS）、中文语言包（全量 `*-zh-cn`）
- Argon 主题 + Argon 主题配置

### 科学上网
- **PassWall2**（luci-app-passwall2）：集成 Xray / Sing-Box / SS / SSR / Trojan / Hysteria2 / TUIC / WireGuard 等协议客户端

### 去广告与 DNS
- **AdGuard Home**（DNS 级广告拦截）
- **SmartDNS**（多 DNS 分流 / 防污染 / 缓存）

### 容器与网盘
- **Docker（dockerd）+ Dockerman**（Web 容器管理）
- **AList**（网盘聚合，挂载阿里云盘/百度网盘/OneDrive 等）

### 文件与存储
- Samba4 文件共享、磁盘管理（Diskman）
- USB3.0 / ext4 / exFAT / NTFS / FAT32 / F2FS / CIFS 挂载
- e2fsprogs、f2fs-tools、ntfs-3g、dosfstools

### 网络服务
- DDNS（阿里云 / 腾讯 DNSPod / Cloudflare 等）
- MWAN3 多线负载均衡、SQM QoS 流量整形
- UPnP、网络唤醒（WOL）、带宽监控（nlbwmon）、流量统计（vnStat2）
- dnsmasq-full

### VPN 与组网
- WireGuard、OpenVPN、Tailscale

### 系统工具
- ttyd 网页终端、文件传输、命令执行
- bash / coreutils / htop / vim-full / nano
- bmon / iperf3 网络诊断、curl / wget / openssl

## 性能调优

- 内核参数针对 **2.5G 转发**优化（rmem/wmem、backlog、somaxconn）
- **BBR 拥塞控制 + fq qdisc**
- conntrack 表与超时优化
- vm 参数调优（swappiness 等）

> 说明：NSS 硬件加速需使用 `immortalwrt_ipq` 专用分支（含 Qualcomm NSS offload）。本固件基于官方 ImmortalWrt 主线以保证稳定性与可复现性，后续可切换到 NSS 分支以获得更高的 NAT 吞吐。

## 首次启动自动化（uci-defaults）

刷入后首次启动自动完成：
1. 主机名 `Athena`、时区 `Asia/Shanghai`、NTP（阿里云/腾讯/中国 NTP 池）
2. 设置 root 密码 `password`
3. 启用 SSH（22）
4. 自动识别 2.4G / 5G 频段并创建 Wi-Fi（SSID `Athena-2.4G` / `Athena-5G`，密码 `athena2024`）
