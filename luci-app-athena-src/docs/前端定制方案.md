# AthenaWrt 前端定制方案 v3（完整版）

> 面向京东云雅典娜 AX6600（RE-CS-02 / IPQ6010）的专属管理界面
> 定位：**产品级体验**，而非「LuCI 换皮 / 加页面」。面向日常使用，兼顾极客深度配置。
> v3 相对 v2 的增量：**一键组网模式切换**、完整信息架构、数据接口清单、设计系统、移动端规范、验收标准。

---

## 一、总体定位与设计目标

| 维度 | 说明 |
|------|------|
| 品牌名 | AthenaWrt |
| 应用名 | `luci-app-athena`（产品级主界面） |
| 架构 | **双轨**：产品级主界面 + LuCI 高级模式入口 |
| 设计语言 | 消费级路由器（大卡片、图标化、留白、响应式） |
| 语言 | 简体中文，预留 i18n |
| 移动端 | **响应式优先**，手机浏览器即用即管 |

**设计目标（可度量）**：

1. 一个普通用户（非极客）**首次 1 分钟**内完成上网 + WiFi 配置（设置向导）。
2. **一屏**看清家庭网络全景：网速、拓扑、在线设备、异常告警。
3. 常见操作（限速、拉黑、访客、家长控制、组网切换）**不超过 2 次点击**。
4. 硬件状态（2.5G 口、三频、eMMC、点阵屏、温度）**实时、准确、可视化**。
5. 极客仍能通过「高级模式」进入完整 LuCI，不丢失任何能力。

## 二、技术架构

### 2.1 双轨架构

- **主界面（产品级）**：深度重写 LuCI 视图 + 自研 UI 组件库 + 响应式，面向日常使用。
- **高级模式**：保留 LuCI 原版完整入口，给极客做深度配置（装插件、防火墙、编译级设置）。
- 后端统一走 `rpcd` / `ubus` / `uci`，两轨共享数据，不重复造轮子。

### 2.2 前端技术选型

| 层 | 选型 | 理由 |
|----|------|------|
| 视图层 | LuCI 原生 JS 视图框架（`view.extend`） | 与系统一致，不引入重型框架 |
| 组件库 | 自研：卡片/拓扑图/环形速率/图标/开关/进度条 | 体积小、可控 |
| 图表 | 内联轻量 SVG | 不引 Chart.js 等重库 |
| 响应式 | CSS Grid + 断点 | 移动端单列、桌面端多列 |
| 状态同步 | 前端轮询（5s）+ 关键操作即时刷新 | 简单可靠 |

### 2.3 目录结构（luci-app-athena）

```
luci-app-athena/
├── root/usr/share/luci/menu.d/          # 菜单注册
├── htdocs/luci-static/resources/view/athena/   # 前端视图
│   ├── overview.js      # 首页全景
│   ├── clients.js       # 设备管理
│   ├── wireless.js      # 无线三频
│   ├── network.js       # 网络 + 组网模式切换
│   ├── storage.js       # 存储共享
│   ├── matrix.js        # 点阵屏
│   ├── led.js           # LED / 按键
│   ├── system.js        # 系统工具
│   ├── wizard.js        # 设置向导
│   └── components/      # 自研组件库
├── root/usr/libexec/athena-status.sh    # ubus 状态聚合脚本
├── root/usr/share/rpcd/acl.d/           # rpcd 权限
└── Makefile
```

### 2.4 数据流

```
硬件 / 系统状态 ──► athena-status.sh（聚合） ──► ubus athena.status ──► 前端 JSON
用户配置 ────────► UCI / rpcd ───────────────────────────────────────► 即时生效
一键组网切换 ────► athena-mode.sh（写 UCI + 开关 NSS） ──► 提示重启/生效
```

## 五、页面功能详设

### 5.1 首页（家庭网络全景）
- 实时网速：下载/上传大数字 + 迷你曲线。
- 图形化拓扑：光猫 → 雅典娜 → 设备分组（手机/电脑/智能家居），点设备进管理。
- 快捷操作：访客网络、游戏加速、一键体检、家长控制 四大按钮。
- 关键状态：在线设备数、三频状态、存储用量、异常告警条。

### 5.2 设备管理（核心）
- 设备列表：MAC 厂商识别类型（手机/电脑/电视/智能家居）、自动命名、在线/离线、连接时长。
- 单设备：**限速**（上下行带宽）、拉黑、重命名、离线提醒。
- 家长控制：按时段断网、网站过滤、设备分组（如「孩子设备」）。

### 5.3 无线（三频）
- 三张频段卡片（2.4G / 5.2G 游戏 / 5.8G），标注芯片来源（板载 IPQ6018 / QCN9074）。
- 每频：SSID / 加密 / 信道 / 频宽（含 160MHz）/ 功率，一键开关单频。
- 访客网络一键开启；Mesh 节点管理；游戏加速开关。

### 5.4 网络（组网）—— 含一键模式切换
- **组网模式一键切换**（见第六章）：主路由 / AP / 单臂 / 旁路由。
- 2.5G WAN：拨号方式（PPPoE/DHCP/静态）、协商速率（2500/1000/100）。
- 端口状态矩阵：四口 + 2.5G，按物理口位置对齐，显示速率/连接状态。

### 5.5 存储（NAS 化）
- eMMC 128G + USB：挂载、容量、作为数据盘。
- 共享：Samba / 网络共享，面向家庭 NAS 场景。

### 5.6 点阵屏（联动底层）
- 显示内容配置：时间 / 实时流量 / 在线设备数 / CPU 温度 / WiFi 状态。
- 亮度 / 夜间模式。

### 5.7 LED 与按键
- 三色灯（红/绿/蓝）各状态颜色自定义、呼吸灯。
- reset/screen/wps 三键动作绑定。

### 5.8 系统
- 一键体检：网络诊断、测速、状态报告。
- 温度监控曲线、固件信息、备份 / 升级（sysupgrade 直接升级）。

### 5.9 高级模式
- 保留 LuCI 原版完整功能入口，极客可深度配置。

## 六、一键组网模式切换（核心交互）

**目标**：用户换组网方式时，不用手改一堆底层配置，一个按钮完成切换。

| 模式 | 自动配置动作 | NSS 状态 |
|------|-------------|----------|
| 主路由 | 2.5G 设主上行，开 NAT + DHCP + 防火墙 | 开 NSS（含 PPPoE） |
| AP 桥接 | 关 DHCP/NAT，全口并入交换机，无线满血桥接 | 不涉及 |
| 单臂路由 | 2.5G 设 trunk，VLAN10=WAN / VLAN20=LAN（DSA） | 开 NSS VLAN offload，关软 offload |
| 旁路由 | 关 DHCP，网关/DNS 指向主路由，代理走 CPU | 关 NSS / flow offload |

**后端实现**：`athena-mode.sh` 脚本根据模式写入对应 UCI 配置并开关 NSS 模块，
切换后提示「是否立即重启生效」。切换前自动备份当前网络配置，可一键回滚。

## 七、数据接口清单

| 功能 | 接口 | 说明 |
|------|------|------|
| 系统/CPU/内存/时长 | `ubus call system board/info` | 基础信息 |
| 实时网速/流量 | `ubus call network.device status` + `athena.status` | 聚合 |
| 接入设备 | `ubus call hostapd.* get_clients` / `dhcp.leases` | 设备清单 |
| 温度 | `/sys/class/thermal/thermal_zone*/temp` | 热区温度 |
| 端口速率 | `/sys/class/net/*/speed`、`ethtool` | 协商速率 |
| 无线三频 | `ubus call network.wireless status` + `iwinfo` | 频段状态 |
| 存储 | `block info`、`/sys/class/block/mmcblk*` | 磁盘 |
| 点阵屏/LED/按键 | 自定义 `athena` ubus 脚本 | 外设 |
| 组网模式切换 | `athena-mode.sh <mode>` | 一键切换 |
| 配置读写 | UCI | 全部配置 |

**聚合脚本**：`/usr/libexec/athena-status.sh` 把硬件状态 + 设备清单 + 流量一次性聚合成 JSON，
前端一次拉取，5s 轮询。

## 十、与底层方案的衔接

产品级首页的每一项（网速、拓扑、设备、点阵屏、温度、组网切换）都依赖底层驱动与
NSS 加速就绪。底层提供数据、前端呈现数据；**一键组网切换**是前后端联动的最典型
例子（前端发指令 → 后端 `athena-mode.sh` 改 UCI + 开关 NSS）。双轨架构下 LuCI
高级模式兜底。两部分合并，即构成完整的「AthenaWrt 定制固件」。
