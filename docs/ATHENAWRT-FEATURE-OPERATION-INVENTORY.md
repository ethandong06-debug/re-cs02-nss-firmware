# AthenaWrt 全站功能与操作清单（C2）

> 基于当前 SPA 与阶段 A 调用链审计静态整理。
> 日期：2026-11-02
> 当前用途：功能重组实施前的逐项对照基线。
> 状态说明：本表中的“真实后端”表示源码存在对应调用，不代表已经完成真机功能验收。

## 1. 状态和处置标签

- **保留**：Athena 的核心价值，继续提供。
- **优化**：保留能力，调整状态表达、操作反馈或安全保护。
- **合并**：并入同一页面/分组，避免重复入口。
- **原生替代候选**：核实当前固件原生 LuCI 后，优先跳转原生页面。
- **移除候选**：无实际动作、误导或无必要的重复功能；删除前仍须全仓库查调用者。
- **危险操作**：需要独立确认、后端校验和单独验收。

## 10. 功能整理实施优先级

### C2-A：可以先整理的低风险项目
1. 菜单/页面分组和中文文案。
2. 首页实时网速主视觉；NSS/ECM 改为只读状态区域。
3. 静态示意拓扑从首页主区域移除。
4. 活跃应用识别加推测标识或隐藏。
5. 删除 SSH 假开关和点阵屏无效入口（先完成全仓库调用者核查）。
6. “检查更新”改为“刷新软件列表”。
7. 灯光页面内部按状态灯/点阵屏/夜间计划重组。
8. 维护页面按计划维护/备份/危险操作重组。

### C2-B：依赖后端整改后再开放/调整
1. 访客网络入口：等待四配置事务化。
2. 拉黑/家长控制：等待 nftables 规则所有权和原子更新。
3. 网络模式/单臂向导：等待 P0 确认票据、保护项 diff 和回退验证。
4. 固件刷写/恢复出厂/配置恢复：等待后端安全修复。
5. USB 格式化：等待设备身份二次校验和并发锁。
6. 服务启停/进程操作：等待路径校验、保护名单和 TERM/KILL 改进。

### C2-C：原生 LuCI 页面核实后再决定
- 接口/协议/防火墙/DHCP。
- 无线高级参数。
- 软件包、进程、服务、日志。
- 固件升级和配置恢复。

## 11. 当前不代表已实施

- “真实后端”只表示源码存在 RPC/脚本动作，不代表动作在当前设备上已通过验收。
- 原生 LuCI 替代项必须核实 Athena 当前固件实际菜单和 ACL，不按上游惯例推断。
- 本轮不删除任何源码入口、不改变 ACL、不改后端、不构建 APK、不操作设备。
