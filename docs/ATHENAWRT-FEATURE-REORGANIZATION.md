# AthenaWrt 全站功能重组与菜单规划

> 阶段：功能整理 C1（现状盘点与目标信息架构）
> 日期：2026-11-02
> 对象：AthenaWrt 1.2.60-r2 当前 SPA
> 状态：规划稿；待逐项确认后实施
> 保护原则：本轮不修改前端/后端源码、ACL、构建工作流或设备配置。

## 1. 本轮目标

本轮不是重写管理后台，而是明确每个页面的职责、入口、功能去留和原生 LuCI 边界，避免：
- 同一项系统能力在 Athena 和原生 LuCI 重复维护；
- 页面显示“开关”但实际没有后端动作；
- 将静态示意、推断结果显示成真实运行状态；
- 将网络模式、升级、恢复、格式化等危险操作放在普通快捷入口；
- 为了视觉统一而提前重写 CSS 或破坏现有功能。

## 2. 总体菜单建议

保留当前八个一级页面，避免用户已经熟悉的导航大改；先调整页面内部的分组和功能归属。

| 顺序 | 一级菜单 | 页面职责 | 核心内容 |
|---|---|---|---|
| 1 | 概览 | 设备运行总览 | 实时上下行速度、CPU/内存、在线设备、WAN/IPv6、关键服务状态 |
| 2 | WiFi | 无线网络快捷管理 | 2.4G/5.2G/5.8G、访客网络、常用无线参数 |
| 3 | 设备 | 终端与访问控制 | 在线/离线设备、备注/改名、认识设备、拉黑、家长控制 |
| 4 | 网络 | 网络专用功能 | 当前网络状态、单臂/VLAN 专用配置、诊断、测速 |
| 5 | 存储 | USB 存储管理 | 设备识别、挂载/卸载、容量、受限文件共享；格式化归入危险操作 |
| 6 | 灯光 | 设备实体灯效 | 三色状态灯、LED 呼吸灯、点阵屏、夜间计划 |
| 7 | 维护 | 维护与备份 | 定时重启、自动备份、备份列表；升级/恢复等高风险功能单独分组 |
| 8 | 高级 | Athena 专属设置与系统入口 | 资源只读信息、Athena 偏好、必要的系统管理入口、原生 LuCI 入口 |

当前不建议新增一级菜单，也不建议把八个页面合并成少数几个大页面。先优化职责和页面内分组，再根据实际使用验证决定是否调整一级菜单。

## 3. 八个页面逐页功能清单

### 3.1 概览

**保留**
- 实时网络上下行速度作为首页主视觉和首要指标。
- CPU、内存、在线设备数。
- WAN/PPPoE、IPv6 状态摘要。
- 常用快捷入口：WiFi、设备、网络诊断。

**调整**
- 首页主卡片明确显示当前速率、峰值/采样状态和单位；数据读取失败时显示“暂不可用/最后更新时间”，不能回退到样例数值。
- 用户此前提出首页以实时网络速度替代硬件加速展示；硬件加速/NSS/ECM 不做可操作开关，可在高级状态区域只读展示。
- “家庭网络拓扑（示意）”不作为在线状态判断依据。建议从首页主视图移除，改为简洁的 WAN/LAN/无线状态摘要；真实物理布线拓扑若要呈现，应基于明确采集的数据并标注数据来源。
- 活跃应用识别若保留，必须标注“根据 DNS/OAF 域名线索推测”，不能描述成 DPI 实时识别；无法可靠映射时显示空状态，不填充演示应用。
- 快捷操作只保留高频、低风险入口；访客网络快捷开关待 WiFi 配置事务保护通过后再决定是否保留。

**移除候选**
- 把静态示意拓扑当成设备实时拓扑的展示。
- 将 NSS/ECM 硬件加速做成开关或首页主 KPI。
- 任何无法区分真实数据与演示数据的活跃应用样例。

### 3.2 WiFi

**保留**
- 三个频段的开关和状态：2.4G、5.2G、5.8G。
- 每个频段的 SSID、密码、信道、频宽、加密方式等常用编辑入口。
- 访客网络开关与设置。
- 无线故障恢复入口，但必须明确恢复内容和断连影响。

**调整**
- 页面首屏只显示三频状态卡和访客网络状态；详细参数进入单独编辑弹窗。
- 访客网络明确展示隔离状态、SSID、频段和配置完整性；后端四份配置未完整时显示异常，不显示“已隔离”。
- 高级无线选项跳转原生 LuCI；Athena 只保留常用参数，避免维护第二套完整无线配置器。
- “恢复默认 WiFi”放入二次确认的危险操作区域，清楚说明三个频段和终端断连影响。

**暂不删除**
- 三频快捷管理是 Athena 的设备适配价值，不能因原生 LuCI 也能配置无线就全部移除。

### 3.3 设备

**保留**
- 在线/离线/全部设备视图。
- MAC、IP、设备名称、连接信息和在线状态。
- 自定义备注、改名、认识新设备。
- 拉黑/解除拉黑。
- 家长控制计划。

**调整**
- “在线”与“离线”必须基于明确的采集规则和最近观测时间；无法确认时使用“状态未知/最近出现”，不要误判。
- 新设备提示与防蹭网合并为设备列表筛选/提醒，不另造重复列表。
- 家长控制按设备展示规则摘要、星期、开始/结束时间和当前生效状态。
- 拉黑与家长控制的规则状态必须区分，避免用户误以为取消家长控制等于解除拉黑。
- 规则写入失败时保留原状态并给出错误原因。

**保留但待整改**
- 拉黑和家长控制后端规则所有权、幂等性和原子更新；在 P1 验收前不扩大功能。

### 3.4 网络

**保留**
- Athena 专用单臂/VLAN 配置向导。
- 当前网络模式和 WAN/IPv6 状态只读摘要。
- 网络体检、连通性检测、Ping/时延测试。
- 宽带测速和单位设置。

**调整**
- 单臂/VLAN 配置明确标记“高级网络操作”，展示当前参数、变更摘要、风险和回退说明。
- 普通 PPPoE、DHCP、静态地址、DNS、防火墙等通用配置优先跳转原生 LuCI，不再复制完整通用配置页。
- 模式切换不作为普通快捷按钮；AP/旁路由等可能关闭 NSS/ECM 或改变网络职责的模式应移入专家区域，并按保护策略限制。
- 体检结果拆成“检测项、检测结果、检测时间、证据/错误”；不能用单一绿色总状态掩盖某项失败。
- 测速与连通性检测区分：测速会产生公网流量，Ping/DNS 检测不代表 PPPoE/IPv6/防火墙全部正常。

**不可触碰**
- 当前 PPPoE、VLAN 2044、IPv6 PD/SLAAC、防火墙/NAT、OpenClash、NSS/ECM 配置与运行逻辑。功能整理不得改变这些配置。

### 3.5 存储

**保留**
- USB 设备和分区识别、容量、文件系统、挂载点。
- 挂载、卸载和状态刷新。
- 当前受限文件共享入口（仅 LAN 管理地址、仅 `/mnt/usb`）。

**调整**
- 格式化从普通磁盘操作中移出，归入危险操作；必须展示准确分区、容量、文件系统和数据清除警告。
- “文件共享”命名改为“USB 文件访问/共享”，明确它只共享指定 USB 目录，不等于完整 NAS。
- 共享密码使用随机生成策略；服务监听范围与目录限制必须由后端强制，不只依赖页面提示。
- 磁盘状态与操作按钮分离：未挂载分区显示挂载；已挂载分区显示卸载；格式化始终需要单独确认。
- 不增加 Samba、媒体服务器或其他 NAS 功能。

### 3.6 灯光

**保留**
- 三色状态灯/呼吸灯。
- 点阵屏总开关、显示项目、亮度/模式（以当前后端真实支持项为准）。
- 夜间模式/计划。
- 点阵屏预览，但明确标记为“预览/模拟”。

**调整**
- LED 与点阵屏在同一页面按“状态灯”和“点阵屏”两个分组呈现；避免拆成多个重复菜单。
- 页面顶部先显示当前硬件状态，再显示控制项。
- 每个开关在后端确认成功后才更新 UI；失败时恢复原值并提示。
- 物理按键说明放在折叠说明区，不占用首屏。

**移除**
- “打开完整管理”当前只显示未集成提示、没有实际页面动作，应删除该按钮或待真实功能完成后再恢复。

### 3.7 维护

**保留**
- 立即重启与定时重启。
- 手动配置备份、备份列表、下载。
- 自动备份策略。

**调整**
- 页面分为“计划维护”“配置备份”“系统升级与恢复”。
- 自动备份显示执行时间、保留份数、最近一次成功时间和失败状态。
- 备份列表区分文件大小、创建时间、来源和校验状态。
- 固件升级必须显示设备兼容性验证结果、文件摘要和升级风险。
- 恢复配置、恢复出厂、固件升级使用独立危险操作区域；不与日常重启/自动备份混排。
- 若当前固件原生 LuCI 页面已确认完整可用，通用固件升级和配置恢复可提供原生入口；Athena 自己的专属自动备份策略仍可保留。

### 3.8 高级

**保留**
- CPU/内存/进程资源只读信息。
- Athena 专属设置：网速单位、主题、默认界面、界面缩放、指标排序等。
- 管理密码修改入口。
- 原生 LuCI 入口作为系统管理完整入口。

**调整**
- 页面分组为“运行状态”“Athena 设置”“系统管理入口”。
- 进程列表与服务管理分开：进程是进程，不等同于服务；不能把 kill 进程描述为重启服务。
- 服务列表优先显示用户安装的第三方服务，关键系统服务只读保护。
- 软件包管理、日志、服务、进程等通用功能先核对当前固件原生 LuCI 是否完整可用，再决定保留 Athena 快捷入口还是跳转原生页面。
- “检查更新”如只执行 `apk update`，文案改为“刷新软件源/软件列表”，不得称为“升级已安装软件”。
- SSH 当前显示“已启用”且点击后只提示始终启用，不具备真实开关行为；移除假开关，必要时改成只读连接信息。
- NSS/ECM 只读展示真实运行状态，不提供启停按钮。

## 4. 通用交互规范

1. **状态可信**：每项动态状态必须有数据来源、采样时间和错误态；RPC 失败不得显示静态样例。
2. **操作反馈**：按钮点击后显示处理中；后端返回成功才更新状态；失败则恢复原值并说明失败步骤。
3. **危险分级**：
   - 普通：只读查看、刷新、页面切换。
   - 需要确认：WiFi 参数修改、设备备注、访客设置、服务操作。
   - 高风险：网络模式/VLAN、配置恢复、固件升级、恢复出厂、USB 格式化。
4. **权限边界**：隐藏按钮不等于安全；后端仍须校验参数、权限、目标和保护名单。
5. **原生跳转**：优先新窗口打开原生 LuCI，保留 Athena 页面状态；嵌入 iframe 需先验证会话、CSP、移动端和跨页面导航。
6. **中文用语**：使用用户能直接理解的名称，避免“trunk/access”等术语作为主要标签；端口状态用“带标签/不带标签”等直白表述。
7. **移动端**：首屏只放关键状态和常用动作；复杂表格允许横向局部滚动或卡片化，不允许整个页面横向溢出。

## 5. 原生 LuCI 替代判定表

| 能力 | Athena 定位 | 原生 LuCI 定位 | 替代条件 |
|---|---|---|---|
| 网络接口/协议/防火墙/DHCP | 专用单臂/VLAN 向导、摘要和诊断 | 通用配置主入口 | 当前设备页面、ACL、权限和保存/回滚行为实测通过 |
| 无线高级参数 | 三频快捷操作 | 完整高级无线配置 | 对应无线页面确实存在且功能完整 |
| 软件包管理 | 可保留轻量入口或跳转 | 通用包管理主入口 | 确认 APK 管理能力、关键包保护和 ACL |
| 进程/服务/日志 | Athena 只读摘要和关键状态 | 通用系统管理 | 核对原生菜单、服务保护和日志功能 |
| 固件升级/配置恢复 | 可提供安全提示和跳转 | 通用维护入口 | 原生升级兼容性、保留配置行为与回滚范围实测 |
| 设备备注/识别/家长控制 | Athena 专属 | 不要求替代 | Athena 独有能力，继续维护 |

不得仅根据上游 OpenWrt/LuCI 常见页面名称推断当前固件一定有对应入口。替代前必须在当前 Athena 固件核实实际菜单、ACL、调用路径和功能。

## 6. 建议的最终页面内部布局

- 概览：实时网速 Hero → 资源/设备 KPI → WAN/IPv6 状态 → 快捷入口 → 可选告警。
- WiFi：三频状态卡 → 访客网络 → 无线高级设置入口 → 故障恢复。
- 设备：统计筛选 → 设备列表 → 新设备提示 → 家长控制规则。
- 网络：连接状态 → 单臂/VLAN 专家向导 → 网络诊断 → 网速测试 → 原生网络管理入口。
- 存储：USB 设备列表 → 分区/容量 → 挂载操作 → 文件访问 → 危险格式化入口。
- 灯光：状态灯 → 点阵屏 → 夜间计划 → 预览 → 物理按键说明。
- 维护：计划维护 → 自动/手动备份 → 备份列表 → 升级与恢复危险区。
- 高级：资源状态 → 第三方服务 → Athena 偏好 → 原生系统管理入口 → 关于/版本信息。

## 7. 实施顺序

### C1：功能归属确认（当前）
- 完成八页功能盘点、保留/合并/移除/原生替代分类。
- 核对每项功能是否真实存在后端调用；无动作入口标记为删除候选。
- 不改源码。

### C2：页面结构和交互设计
- 输出每页线框结构和操作流程。
- 确定快捷入口、危险操作分区、空状态/错误状态。
- 先确认当前原生 LuCI 页面清单。

### C3：功能调整实施
- 先做低风险页面结构、文案和导航。
- 后做后端相关功能合并与危险操作保护。
- 每页独立提交，避免一次重写整个 SPA。

### C4：视觉与响应式
- 最后统一 CSS、组件间距、移动端适配和主题表现。
- 不把视觉调整与网络后端重构混在同一批次。

### C5：功能回归
- 每个按钮对应真实 RPC/参数/返回值。
- 只读状态、普通操作、危险操作分层验收。
- 网络保护项单独核对；当前设备不做未经授权的危险测试。

## 8. 当前明确不做的事项

- 不更改 PPPoE、VLAN 2044、IPv6 PD/SLAAC、防火墙/NAT、OpenClash、NSS/ECM。
- 不移除 NSS/ECM 模块或服务，不增加硬件加速开关。
- 不增加 NAS/Samba。
- 不重写整个 SPA，不提前大规模改 CSS。
- 不删除任何底层后端能力，除非调用者盘点和替代入口验证完成。
- 不在当前在线设备上执行网络模式切换、固件刷写、配置恢复、恢复出厂或磁盘格式化。

## 9. 本轮结论

- 已基于当前 SPA 的八个主页面和可见控件形成目标信息架构。
- 已将首页实时网速作为首要展示，NSS/ECM 仅只读显示。
- 已将访客网络、拉黑/家长控制、网络模式、固件升级、配置恢复、USB 格式化列为需要后端保护的功能。
- 已识别 SSH 假开关和点阵屏未集成入口为移除候选。
- 本文是功能整理规划，不代表已经删除、合并或修改任何功能。
